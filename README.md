## Mundus is divided into 6 "Modes": 4 for the active creation process, 2 for managing it:

### Atlas
Everything begins here, where you can:
- Create, edit the details, delete and see all your projects (Each one is an independent Mundus)
- Upload an individual Mundus' backup file, change app theme or access settings (top right)
- Access each Mundus (click to open)

### Writing Mode
Opening a Mundus brings you here, where the magic happens, you can find all the familiar features of a document editor and more, including:

In the top bar
- Folder button to see the scenes in the current folder or add a new one
- Auto format the active document to fix pagination errors
- Import / Export the active document from / to various formats
- A Dropdown menu to assign Draft / Review or Complete status to the active document
- A checkpoint system to easily save and restore a document without exiting the app, useful for trying out versions
- Auto save with instant / timed intervals or off options
- Focus mode to hide the top toolbar
- Zen mode to hide the entire UI, leaving just you and the text
- Support for uploaded custom Fonts and GoogleFonts, in the font selection menu (both sync when cloud is configured)
- A dictionary to add custom words or names (The names of characters or Codex entries you create are automatically added!)
- Adding images to the document, resizing and aligning them, including captions and an option to sync them online via free hosting
- Search and replace throughout the active document
- Speech-to-text via Whistle, fully local, useful for brainstorming sessions
- A spelling check, spelling review drawer with the list of errors in your document and an autocorrect engine based off Harper
- A Timeline button to add a duration to the active document's scene, shows on the timeline in Lore Mode
- An "In this Scene" drawer which automatically detects characters and Codex entries present in the document so you can easily reference them, keep track of who and what is involved or make a quick edit to them

In the bottom bar
- Page number
- Document stats
- Set a writing goal for the document / session (the bar fills with color with completion, toggleable in settings)
- Active document format, last save time, zoom level controls

### Mundus View

### Characters Mode 

Lets you bring your stories' characters to life, create a card for each one to always have the full picture available and to take advantage of Mundus' integration features, here's what it can do:
- Search characters (looks inside all fields) 
- View all your characters organized by collapsible factions or families
- Filter by tags (results must have all selected tags)

Character cards (create a character and click them to edit their card):
- Set name, titles, portrait picture, status and gender
- Assign story roles, factions and family alignments
- Describe relations, including parents, partners, siblings and children (partners and sibling automatically apply to all involved)
- Assign custom attributes or tags
- Specify date and place of birth and death
- Describe appearance 
- Describe everything you want about them, their backstory, their motives, their personality etc etc
- Author notes for upcoming plot twists or events
- A section that shows in which documents the character is detected

Family Tree Graph:
- Automatically builds family trees from the assigned relationships
- Can be filtered similarly to the characters

### Lore Mode 
The very foundation of your Mundus, an archive-like tool to remember everything you created in it:

Codex (The Encyclopedia) 
- Create an entry for anything outside characters
- Assign each entry to its category (customizable)
- Upload images for each entry (support for multiple)
- Describe entries to never forget any detail

Timeline 
- Place customizable events of various nature on the timeline
- See when each document you wrote sits in the story (requires the scene to be assigned a start and duration)
- See each character's lifespan
- Filter or collapse sections to only see what you need

Story Flow 
- Link scenes to one another based on their relation (leads to, causes, flashback etc) with automatic positioning and color-coded link lines creation, to never lose track of your plotlines 
- Filter scenes by chapter to only see what you need
- Allows manual repositioning and editing

### Map Mode 
Made to let you visualise your world:
- Upload any image file as the Mundus' map
- Pin markers on it to place locations or any other Codex entry
- Get the entry's info by clicking on the pin, or edit its details on the fly
- Filter the shown markers by category
- Markers are placed with percentage coordinates, meaning you can upload a higher or lower resolution version of the same image without breaking your existing ones

## Installing

- Read below to figure out which file you want / need based on your operating system
- Go to [Releases](https://github.com/NotBedd/Mundus/releases) (click the link or go to it manually, should be on the right side of this page on desktop and at the bottom on mobile) 
- Look into the "Assets" and download the file you want

**WINDOWS**:
you have two options:

1. The "portable.exe" runs the app inside the folder you place it in and keeps all data there, you can move it around as you like
2. The "setup.exe" will install the app on the pc fully like others do, it'll store data in the default programs folder, create its own shortcut in the start menu etc

Congratulations, you are done!

**LINUX (rpm & deb)**:
you have two options:

1. The "AppImage" runs the app inside the folder you place it in and keeps all data there, you can move it around as you like
   - AppImages work on all distros 
3. The "deb"/"rpm" will install the app on the pc fully like others do, it'll store data in the default programs folder, create its own shortcut in the start menu etc
   - If you use Fedora or other Red Hat distros pick the rpm file
   - If you use Ubuntu, Debian, Mint or other Debian-based distros pick the deb file

Congratulations, you are done!

**MACOS**:
you have two options:

1. The "zip" when extracted gives you the app bundle, it runs the app inside the folder you place it in and keeps all data there, you can move it around as you like
2. The "dmg" will install the app on the pc fully like others do, it'll store data in the default programs folder, create its own shortcut in the start menu etc

Congratulations!

## Updating

**WINDOWS**
- Download the same file type you already have (portable or setup)
1. If you have the portable, move the newer version .exe file over to the older one's folder, replace the older version, you're done
2. If you have the fully installed version, run the newer setup.exe, select the option you chose when first installed (for user or for pc, it'll say at the bottom whether it detects a pre existing install or not), once the install is complete you are done

**LINUX**
- Download the same file type you already have (AppImage or deb/rpm)
1. If you have the AppImage, move the new version one where you have your current one, replace the old one, make the new one executable (Right-click it → Properties → Permissions → check "Allow executing file as program), you're done
2. If you have the fully installed version, double click the newer deb/rpm, click "upgrade" or "install" in the window that opens, you're done

**MACOS**
- Download the same file type you already have (zip or dmg)
1. If you have the .zip, double click the newer version one to get the newer Mundus.app, move it (Mundus.app) to where you keep your current one, replace the old one, you're done
2. If you have the fully installed version, double click the newer .dmg, drag the Mundus icon into your Applications folder, click "replace", you're done

### Android
- Download and install the newer apk, it will ask to update, say yes (might also ask for permission again as its not signed)

### iPhone & iPad
