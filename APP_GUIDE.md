## Mundus Atlas
The Atlas is the app's starting screen, in the top right you can see 3 buttons, from left to right, their functions are:
- Restore a Mundus from a backup: You can upload the backup of an individual Mundus project (which you can create from Mundus View, we'll get there later) and restore it, or merge the changes if you have an older version of the same project
- Toggle between dark and light them (app-wide)
- Open the settings menu

Under the logo you'll see all your Mundus projects, at first launch it will be empty, click the box to create a new one. 
In the menu that opens you can set the details as you want, including the pages format

## Writing Mode
Writing mode is the page you'll spend most time in and the one with most buttons and integration by far, let's go over them in sections:
### Top bar 
#### Left side (moving left to right)
- The folder icon button lets you see the folder the current document belongs to, and also create a new document in said folder
- The bar to its right is the document name, change it from here
   
Below them you have
- Undo and redo buttons for the last actions
- The font menu, opening it lets you select the font from included ones, import from GoogleFonts or upload a custom one (all of these get synced to the cloud if configured)
- Next to it is the size menu, you can select an option from the list or edit it manually
- Then there's the "text type" menu, clicking it it lets you assign pre made styles for headers or dialogues
  
After it there are the text style buttons
- Bold, Italics, Underline, Strikethrough
- Next to them are the turn the selected text into uppercase and lowercase buttons
   
Then the colors section
- Text color button opens a menu, the first color (the one split between black and white) automatically assigns the correct color based off the theme. Above there are some fixed options, below is the custom color wheel and the last 3 custom colors used
- Highlighter button lets you highlight the selected text if you pick a color (this automatically disables so that if you keep writing the rest doesn't get highlighted). If you enable the highlighter with no text selected, it will stay enabled until you manually toggle it off

Alignment options
- The 4 buttons align the selected text (or the one written after enabling) left, center, right and justified respectively

List options
- The 3 buttons turn the selected text (or the one written after enabling into a bullet list, a numbered list or a quote/dialogue respectively

Special features
The next 4 buttons each have special features
- The Dictionary button opens the dictionary menu popup, in it you can enable spellchecking (english only for now) and add custom words to the dictionary to exclude them from the spellcheck, note that character names and lore entries created in Codex are automatically treated as custom words even if they don't show)
- The Images button lets you upload an image to include in the document where the cursor is at the moment of click. Added images can be resized to fixed intervals (small/medium/large) or manually, can be aligned in the page and have a captions text field to add a classic illustration-like caption
- The Search button lets you search for words and phrases in the document and replace them with another text. The buttons to the right are options to enable case-sensitivity and "whole words" which you can use to search strings of letters inside bigger words or not
- The Microphone button is used for the Speech-to-text feature. When you first click it the pill appearing in the bottom right will display "downloading ...", wait a moment for the model to download, after the text disappears you'll be left with the recording time and a button to stop. When the button is clicked, Whistle starts listening from your main microphone and transcribes what you say. This is especially useful to quickly put down an image of a scene you have in your head before it loses detail
